# Simulador de Normativa de Celulares en el Aula

## Descripción
Este proyecto fue realizado para la materia Laboratorio de Programación (LPR) de 5° año.

Consiste en un simulador de asesoramiento normativo escolar basado en la Ley 15.678, que permite representar diferentes situaciones relacionadas con el uso de celulares dentro del aula.

## Objetivo
Desarrollar un programa en Python que utilice estructuras condicionales para determinar si está permitido utilizar el celular, si corresponde gestionar una emergencia familiar o si debe permanecer guardado.

## Tecnologías utilizadas
- Python 3
- Visual Studio Code
- Git
- GitHub

## Funcionamiento
El programa utiliza dos variables principales:

- `autorizacion_docente`: indica si el docente autorizó el uso del celular.
- `emergencia_familiar`: indica si existe una emergencia validada por preceptoría.

Según los valores de estas variables, el sistema muestra tres posibles respuestas:

1. Acceso permitido.
2. Canalización institucional.
3. Restricción del uso del celular.

## Estructuras utilizadas
- Variables booleanas.
- Condicional `if`.
- Condicional `elif`.
- Condicional `else`.
- Instrucciones `print()`.

## Ejecución
1. Abrir el proyecto en Visual Studio Code.
2. Abrir el archivo Python.
3. Ejecutar el programa.
4. Observar el mensaje correspondiente según las variables configuradas.
